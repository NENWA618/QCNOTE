## 开始使用

打开站点，点“开始记录”进入控制台（`/dashboard`）就能写。**不需要注册**：没登录时是访客模式，笔记以明文保存在当前浏览器里。

登录（Google / GitHub / Discord）之后：

- 笔记在本机**加密**保存，见[数据存在哪里](#数据存在哪里)
- 访客模式下写的笔记会自动并入你的账号
- 可以使用个人主页、公开笔记、AI 模型接入、排行榜

第一次打开控制台时会看到一个加载界面，它在准备本机存储。如果超过 8 秒还没好，界面会说明可能的原因（浏览器存储繁忙、在多个标签页里同时打开了 QCNOTE）并提供“重新加载”；加载失败时也会提示原因。你的笔记一直保存在本机，重新加载不会丢失。

### 安装为应用

在 Chrome、Edge、Safari 等浏览器打开站点，点地址栏的安装图标，或在菜单里选“安装应用 / 添加到主屏幕”，之后可以像普通应用一样从桌面或主屏幕打开。访问过的页面离线也能打开；没访问过的页面离线时显示提示页。

## 写笔记

在控制台点“新建笔记”，或点任意一张笔记卡片打开编辑器。

| 项目     | 说明                                                                                                                                                                                |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 标题     | 可留空，列表里显示为“无标题”                                                                                                                                                        |
| 内容     | Markdown（编辑区有语法高亮，Ctrl/Cmd+Z 可逐步撤销）；数学公式用 `$...$`（行内）或 `$$...$$`（独立成行）；流程图、时序图等用 ` ```mermaid ` 代码块；底部状态栏显示字数和预计阅读时间 |
| 分类     | 生活、工作、学习、灵感、其他                                                                                                                                                        |
| 颜色主题 | 卡片左侧色条和图谱节点的颜色                                                                                                                                                        |
| 标签     | 用逗号分隔，中英文逗号都可以，例如 `读书, 心理学`                                                                                                                                   |

- **双向链接**：在正文里写 `[[另一篇笔记的标题]]` 就能引用它；被引用的笔记会自动出现反向链接。在预览里点链接可直接跳过去。输入 `[[` 会弹出笔记标题的补全菜单，用 `↑` `↓` 选择，`Enter` 或 `Tab` 确认，`Esc` 关闭。
- **格式工具栏与快捷键**：正文上方的工具栏提供加粗、斜体、删除线、行内代码、标题、列表、待办、引用、链接和双链；`Ctrl/Cmd+B`、`Ctrl/Cmd+I`、`Ctrl/Cmd+K` 分别是加粗、斜体、插入链接，再按一次取消。在列表、待办、引用的末尾按 `Enter` 会自动续写下一项，空项再按一次结束列表；列表项上按 `Tab` / `Shift+Tab` 缩进或取消缩进（在普通文字上 `Tab` 仍然是移动焦点）。这些编辑都支持 `Ctrl/Cmd+Z` 撤销。
- **字数**：状态栏的字数按中文每字一个、英文每词一个计算，鼠标停在上面可以看到不含空白的字符数。
- **文字着色**：在正文里选中一段文字，会出现色板，点一个颜色给它上色，点“清除”去掉颜色。
- **预览**：点“预览”查看渲染效果，再点“编辑”回来。屏幕足够宽（约 1024px 以上）时还有“分屏”：左边写、右边实时预览，这个选择会被记住。
- **保存与关闭**：点“保存”会保存并关闭编辑器；按 `Ctrl/Cmd+S` 会保存但继续留在编辑器里，适合边写边存。有未保存的更改时，标题旁会显示“未保存”；这时点“取消”或按 `Esc` 会先问你是否放弃更改，直接关闭或刷新浏览器标签页时浏览器也会提醒。
- **版本历史**：每次保存都会把之前的内容存为一个版本，每篇最多保留最近 20 个。点“历史”可以对比差异，并恢复到任意版本。
- **删除**：点“删除”会把笔记移到回收站。

## 浏览与查找

### 快速跳转与命令

按 `Ctrl/Cmd+K`（或点工具栏的 🔎）打开面板：

- 直接输入标题的几个字就能跳到那篇笔记，不必输入连续的字，`pjt` 也能找到 `project`；也可以用标签或分类找。没有输入时列出最近编辑的笔记。
- 输入的内容在已有标题里找不到时，面板会提供“新建笔记「…」”，用你输入的文字作标题新建。
- 同一个面板里还能切换视图、打开回收站、切换深色 / 浅色模式、导出数据。
- `↑` `↓` 选择，`Enter` 执行，`Esc` 关闭。编辑器打开时不响应此快捷键。

### 四种视图

控制台右上角可切换视图：

| 视图   | 用途                                                                                  |
| ------ | ------------------------------------------------------------------------------------- |
| 列表   | 笔记卡片。点卡片上的 `#标签` 只看带这个标签的笔记，可以同时选多个，列表上方能逐个取消 |
| 日历   | 按最后修改日期的热力图。点某一天，会列出那天修改过的笔记，点笔记即可打开              |
| 时间线 | 按月、按天倒序排列所有笔记                                                            |
| 图谱   | 笔记是圆点，`[[双链]]` 是连线，圆越大表示引用越多。点圆点打开笔记                     |

### 搜索

在左侧（手机上在顶部）的搜索框输入关键词。按 `/` 可以随时把光标放进搜索框，按 `Esc` 或点 ✕ 清空。

支持字段过滤和逻辑组合：

| 写法                        | 含义            |
| --------------------------- | --------------- |
| `title:周报`                | 标题包含“周报”  |
| `content:React`、`tag:读书` | 正文 / 标签匹配 |
| `category:工作`             | 分类            |
| `date:` 加日期或日期范围    | 按日期筛选      |
| `AND`、`OR`、`NOT`          | 组合多个条件    |

**语义搜索**（默认关闭）：勾选搜索框下方的“语义搜索”后，还能按意思找到措辞不同的笔记。模型在你的浏览器里运行，第一次开启时需要下载，笔记内容不会离开设备。

### 排序与分类

在侧边栏（手机上点“筛选”展开）可以按时间、标题或分类排序，并按分类筛选。有筛选条件时，标题旁会显示“匹配数 / 总数”；筛完一篇都没有时，可以一键“清除筛选”。

## 整理

控制台右上角的“更多”菜单里：

- **回收站**：恢复或永久删除笔记。
- **冲突**：同步时两边都改过的笔记，在这里逐条选择保留哪一份。
- **标签管理**：查看所有标签及数量；重命名（`Esc` 取消）、删除标签；点标签名查看它下面的笔记并直接打开；勾选多个标签后，可以给“带有这些标签的笔记”批量加上或移除某个标签。
- **云端同步**：见[同步与备份](#同步与备份)。
- **导出 / 导入数据**：导出为 JSON 备份文件，或从备份导入。
- **清空所有笔记**：需要输入“清空”二字确认，且无法撤销。

## 同步与备份

每台设备上的笔记库是独立的，**笔记不会自动出现在别的设备上**。要在多台设备间同步，在“更多 → 云端同步”里配置 WebDAV 或 OneDrive。

同步只合并“上次同步以来哪一边改了什么”，删除也能同步到另一边，不依赖设备时钟是否准确。远端文件解不开（例如两边的加密密钥不一致）时会直接停止，不会覆盖远端。

### WebDAV

支持 Nextcloud、坚果云等任何 WebDAV 网盘。

1. 填写 WebDAV 地址、用户名、密码（或应用密码）和远程文件路径（默认 `notes.json`）。
2. 可选填写**加密密钥**：填了，上传前会在本机加密；不填，远端就是明文 JSON。多台设备要填同一个密钥。
3. 可选开启**自动同步**，选择间隔（5 分钟到 1 小时）和遇到冲突时的处理方式（留给我手动处理 / 自动采用本机版本 / 自动采用远端版本）。
4. 点“保存配置”。自动同步设置在保存后生效。

| 按钮                  | 作用                                                       |
| --------------------- | ---------------------------------------------------------- |
| 立即同步              | 双向合并：下载远端的更改，合并后再上传。日常用这个         |
| 更多操作 → 仅下载合并 | 只把远端的更改合并到本机，不上传                           |
| 更多操作 → 覆盖上传   | 用本机笔记覆盖远端，其他设备尚未同步的修改会丢失（会确认） |
| 更多操作 → 清除配置   | 删除本机保存的配置，远端文件不受影响（会确认）             |

### OneDrive

目前需要手动粘贴 Microsoft Graph 访问令牌（Access Token）和文件路径，可选加密密钥（需与其他设备一致）。修改后点“保存并同步”或“仅保存”；两边都改过的笔记保留较新的一份，另一份存进版本历史。令牌默认隐藏，可点“显示”查看。

### 备份

“更多 → 导出数据”会下载一个包含全部笔记的 JSON 文件。它是**明文**，请存放在可信的地方。

## 数据存在哪里

| 你是                 | 笔记存在哪里           | 是否加密                                       |
| -------------------- | ---------------------- | ---------------------------------------------- |
| 访客                 | 当前浏览器             | 否                                             |
| 登录用户             | 当前浏览器             | 是。标题、正文、标签、分类、版本历史等都是密文 |
| 发布到个人主页的笔记 | 服务器                 | 否，任何人可见                                 |
| 同步文件             | 你的 WebDAV / OneDrive | 填了同步加密密钥才加密，否则是明文 JSON        |

登录用户的笔记由浏览器本地的一把密钥加密，这把密钥再由服务器为你的账号保管的密钥保护。单独拿到服务器的数据库，或单独拿到你的浏览器数据，都解不开笔记。但服务器能取得你账号的密钥，所以这**不是端到端加密**。

还需要知道：

- **单处登录**：每个账号同一时间只能在一处登录。在另一台设备或浏览器登录同一账号后，之前登录的那一处会被退出，需要重新登录；同一浏览器的多个标签页共用同一个登录，不受影响。账号安全取决于你的 Google / GitHub / Discord 账号本身。
- **离线**：登录用户离线时拿不到密钥，笔记库会显示“未解锁”，恢复联网后自动重试；访客模式离线可以正常使用。
- **解不开的笔记**会被暂时隐藏，控制台会提示数量；它们不会被修改、删除或同步，原始数据留在本机。
- 不启用第三方分析、广告或追踪。完整说明见[隐私政策](https://qcnote.com/privacy)。

## 个人主页与公开笔记

登录用户有一个公开主页 `/u/<你的用户 ID>`，显示头像、用户名、简介、加入时间和公开笔记，**不显示邮箱**。在“个人资料”（`/profile`）里编辑；头像地址留空时显示用户名首字母。

- 在编辑器里点“发布到主页”，才会把这篇笔记的标题、正文、标签和文字着色以**明文**上传。未发布的笔记永远不会上传。
- 发布的是当时的一份副本。之后改了本地笔记，需要点“更新发布”，编辑器和卡片上会提示“有更新”。
- 可以随时“取消发布”，服务器上的副本会立即删除。删除已公开的本地笔记时，会询问是否一并取消发布。
- 每人最多 100 篇，标题不超过 200 字，正文不超过 100KB，标签不超过 20 个。
- 公开页面不会被搜索引擎主动收录，但无法阻止看过的人复制内容；管理员可以下架违规内容。
- 违反规定时，管理员可以关闭你的个人主页和公开笔记：别人无法再访问，你也无法发布、更新发布或取消发布公开笔记（控制台和个人资料页会说明原因）。公开笔记不会被删除，而是保留；本地笔记不受影响。

## 更多功能

- **AI 生成笔记**（`/models`，需登录）：填写任意 OpenAI 兼容的 Chat Completions 接口地址、模型名称和 API Key，然后在右侧输入问题，回复会保存为一篇新笔记（`Ctrl/Cmd+Enter` 发送）。请求由浏览器直接发往你填写的地址，不经过 QCNOTE 服务器；API Key 加密保存在本机。目标服务需要允许浏览器跨域访问（CORS）。
- **叠界迷宫与排行榜**（`/diejie`、`/leaderboard`）：每天一张全站相同的迷宫（另有不计榜的自由练习）：先有 5 秒光源记路线，熄灭后凭记忆走出去。成绩 = 用时 + 罚时（撞树 +3 秒，回光 +4 秒，最多 2 次），越低越好；登录后的成绩计入当天排行榜，每天 0 点（UTC+8）重置。
- **推送通知**：允许通知后可以收到官方消息；在“个人资料”里随时订阅或取消。订阅属于当前浏览器，换设备需要重新订阅。
- **网页剪藏**：浏览器扩展目前是开发版，安装方法见 [extensions/README.md](../extensions/README.md)。
- **深色模式**：页头的月亮 / 太阳按钮。

## 常见问题

**换了电脑，笔记怎么不见了？**
笔记只存在原来那台设备的浏览器里。请在原设备上配置 WebDAV / OneDrive 同步（或导出备份），再在新设备上同步（或导入）。

**登录后显示“设备未解锁”。**
多半是离线，联网后会自动重试。如果一直不行、且提示登录会话失效，说明这个账号已在别处登录，点控制台顶部的“重新登录”即可（这会让别处的登录退出）。

**清除浏览器数据会怎样？**
本机的笔记会被一起清掉。重要的笔记请先同步或导出备份。

**同步提示冲突。**
到“更多 → 冲突”逐条选择保留哪一份。有冲突的笔记会暂停同步，其余笔记照常同步。
